발렌라이프 내부 공유용

클로드로 메타 광고 셋팅하기

메타 광고 셋팅 전체를 클로드가 대신 하도록 만든 스킬이에요. 스킬은 팀별로 두 개예요.
처음 한 번만 준비해 두면, 그다음부터는 "메타 셋팅해줘"라고 말하면 돼요.

발렌라이프 내부 공유용 문서예요. 회사 밖으로 전달하지 마세요.

연결 구조

클로드가 메타에 들어가는 길

클로드는 회사 앱 Valen Marketing Automation이라는 문을 지나 메타에 들어가요. 문은 관리자가 한 번 열어주고, 출입증(토큰)은 팀원마다 따로예요.

#무엇누가언제어디서
1메타 계정 인증 · 등록팀원 각자처음 한 번
(3분)		developers.facebook.com → 「내 앱」
2토큰(출입증) 받기팀원 각자60일마다Graph API 탐색기 → 토큰 디버거에서 연장
3메타 커넥터 연결 (소재 만들기용)팀원 각자처음 한 번클로드 설정 → 커넥터 → 「커스텀 커넥터 추가」 → 주소 https://mcp.facebook.com/ads (브라우저로 열면 오류처럼 보이는 게 정상)

출입증(토큰)은 사람마다 따로라서, 한 사람의 토큰이 만료돼도 다른 사람은 영향이 없어요. 누가 무엇을 바꿨는지도 사람별로 기록이 남아요.

꼭 있어야 해요

회사 앱이 하는 일

회사 앱은 클로드가 메타에 직접 · 한꺼번에 · 정해진 시각에 일하게 해주는 통로예요. 글로벌팀은 Valen Marketing Automation 앱 하나를 같이 써요. 관리자(Tavi)가 팀원에게 「앱 테스트」로 할당해요. 팀원은 그 앱으로 각자 토큰(60일)을 받아요.

하는 일메타 커넥터만 있을 때회사 앱(토큰)이 있을 때
소재 업로드한 장씩 파일 선택내 맥 폴더를 통째로 한 번에 (큰 영상 포함)
광고 만들기하나씩수십 개를 한 번에
예산 예약안 돼요정한 시각에 자동으로 바꾸고 기록
이미지·링크 교체광고를 새로 만들어야 해요광고는 그대로, 성과도 유지
심사 결과물어볼 때마다 조회뒤에서 계속 확인하고 알려줘요

메타 커넥터는 소재(이미지+문구)를 만들 때 쓰고, 회사 앱은 나머지를 빠르게 해요. 그래서 둘 다 연결해 둬요.

처음 한 번

시작하는 순서

클로드 앱의 「Code」 탭에서 진행해요. 「Chat」·「Cowork」 탭이 아니에요.

코드 탭은 내 맥의 소재 폴더를 바로 열고, 업로드와 예산 예약을 직접 실행해요. 그래서 제일 안정적이에요.

  1. 메타 아이디 확인

    1분

    페이스북에 로그인이 되면 OK예요. 없으면 먼저 만들고, 관리자에게 아이디를 알려서 권한 3개를 받아요.

    페이스북 로그인 ↗아이디 만들기 ↗광고 관리자 ↗

  2. 클로드 준비

    3분

    클로드 앱 「Code」 탭 → 터미널에서 스킬 설치 한 줄 → 새 세션(+)

  3. 메타 연결

    3분

    설정 → 커넥터 → 「커스텀 커넥터 추가」 → 이름 meta 커넥터 · 주소 아래 주소 → 연결 → 광고 계정·페이지 전부 체크하고 허용

    https://mcp.facebook.com/ads

    클로드 커넥터 설정 ↗

  4. 메타 계정 인증 · 등록

    3분 · 처음 한 번

    developers.facebook.com → 회사 광고 계정 권한을 받은 페이스북 아이디로 로그인 → 오른쪽 위 「내 앱」 → 약관 동의 → 전화번호 인증 → 이메일 확인 (본인만 할 수 있어요)

    계정 인증·등록 ↗등록 화면 바로가기 ↗

  5. 토큰 받기

    5분

    Graph API 탐색기에서 앱 「Valen Marketing Automation」 → 사용자 토큰 → 권한 6개만 추가 (전체 추가 ❌) → 「Generate Access Token」. 이 토큰은 1~2시간짜리라 아직 복사하지 않아요.

    Graph API 탐색기 ↗

    [권한 6개 항목] 이 6개만 하나씩 검색해서 추가해요
    ads_managementads_readbusiness_managementpages_read_engagementpages_show_listpages_manage_ads
    Graph API 탐색기 (실제 화면)
    1. 오른쪽 「Meta 앱」에서 Valen Marketing Automation 선택
    2. 「사용자 또는 페이지」 → 사용자 토큰
    3. 「권한 추가」에서 아래 6개만 하나씩 검색해서 추가 (전체 추가 ❌)
    4. 파란 Generate Access Token → 페이스북 창에서 계정·페이지 전부 선택 → 허용
    5. 생긴 긴 글자 왼쪽 ⓘ → 「액세스 토큰 도구에서 열기」 (아직 복사하지 않아요. 1~2시간짜리예요)

  6. 토큰 디버거로 60일 확장

    5분 · 60일마다

    5번에서 받은 토큰 왼쪽 ⓘ → 토큰 디버거 → 맨 아래 「액세스 토큰 확장」 → 두 달 뒤 날짜가 나온 새 토큰을 복사 → 클로드에게 "복사했어". 채팅창에는 붙여넣지 않아요.

    토큰 디버거 ↗

    2. 아래에 「○월 ○일에 만료되는 새 액세스 토큰」이 두 달 뒤 날짜인지 확인

    토큰 글자와 개인 정보는 가려 둔 실제 화면이에요.

  7. 셋팅 정보 알려주기

    5분

    클로드에게 아래를 알려줘요. 모르는 건 클로드가 하나씩 물어봐요.

    1. 소재 폴더 — 다운로드 폴더 안 행사 폴더 (하위 폴더 하나 = 광고세트 하나)
    2. 지역 — 일본 또는 북미
    3. 연령 — 예: 18–65세
    4. 성별 — 여성 / 남성 / 전체
    5. 예산 시트 — 구글 시트 링크, 안 열리면 캡처
    6. 브랜드 · 판매처 · 기간 — 예: 셀프뷰티 · 큐텐 · 10/20 0시 ~ 10/26 밤 12시

  8. 클로드가 셋팅

    자동

    캠페인·세트는 꺼진 상태, 광고만 켜진 상태로 셋팅돼요. 세트가 꺼져 있어서 돈은 안 나가요.
    집행할 때는 클로드가 꼭 "켤까요?"라고 물어보고, 확인받은 뒤에 캠페인·세트를 켜요.

막혔을 때

「개발자로 등록해야 합니다」가 뜰 때

무슨 뜻앱은 할당됐는데, 그 사람이 아직 메타 계정 인증 · 등록을 안 한 상태예요. 이대로는 토큰을 못 받아요
누가 해요본인만 할 수 있어요. 본인 전화번호로 인증해서 관리자가 대신 못 해요
어떻게회사 광고계정 권한을 받은 페이스북 아이디로 developers.facebook.com → 오른쪽 위 「내 앱」 → 약관 동의 → 전화번호 인증 → 이메일 확인 → 완료
끝나면앱이 이미 할당돼 있으면 자동으로 연결돼요. 아직 할당 전이면 관리자가 「사람 할당」 → 부분 액세스 「앱 테스트」로 넣어줘요
관리자 확인법비즈니스 설정 → 계정 → 앱 → 회사 앱 → 「사람」 탭에서 이름 옆에 안내 표시가 남아 있으면 아직 등록 전이에요

토큰

자주 묻는 것

왜 60일만 돼요?

메타가 보안 때문에 사람 계정으로 받는 토큰은 최대 60일까지만 쓰게 정해놨어요. 그냥 받으면 1~2시간, 연장하면 60일이 끝이에요.

토큰이 오래 살아 있을수록 잃어버렸을 때 위험해서 주기적으로 새로 받게 해요. 만료 없는 토큰(시스템 사용자 토큰)도 있지만 회사 비즈니스 관리자가 따로 만들고 앱 검수를 거쳐야 해요. 그래서 지금은 60일마다 새로 받고, 7일 전에 클로드가 미리 알려줘요.

⛔ 토큰은 채팅창에 절대 붙여넣지 마세요

클로드 채팅창, 슬랙, 카톡, 메일 어디에도 붙여넣으면 안 돼요. 「복사」 후에는 클로드에게 "복사했어"라고 말만 하면 돼요.

토큰은 회사 광고 계정 열쇠예요. 가진 사람은 누구든 광고를 만들고 켜고 예산을 바꿀 수 있어요. 즉 회사 돈을 쓸 수 있어요. 채팅에 붙이면 대화 기록(내 맥·서버)에 그대로 남고, 화면 공유나 캡처로 다른 사람 눈에 띌 수 있어요.

실수로 붙여넣었다면 그 토큰은 버리고 바로 새로 받아요.

메타가 처음이라면

광고는 3층이에요

캠페인행사 하나. 예) 10월 아마존 프라임 감사제
광고세트누구에게(지역·나이·성별) · 하루 얼마 · 언제까지. 예) 브랜디드 / 바이럴 / 배너영상 / 릴스
광고실제로 보이는 것. 이미지나 영상, 일본어 문구, 누르면 가는 상품 페이지

필수로 알려줄 6가지

항목예시
토큰 연결위 5·6단계. 토큰은 60일짜리예요. 클로드가 매번 남은 날짜를 확인하고, 만료 7일 전부터 "토큰 새로 받으세요"라고 알려줘요
소재 폴더다운로드 폴더의 행사 폴더 안을 브랜디드 · 바이럴 · 배너영상 · 릴스로 나눠요. 폴더 하나가 광고세트 하나예요
지역국내팀은 대한민국, 글로벌팀은 일본 또는 북미(미국, 미국+캐나다)
연령18–65세
성별여성 / 남성 / 전체
예산 시트구글 시트 링크. 안 열리면 캡처

클로드가 하는 셋팅 순서

파일명 정리→캠페인→광고세트→소재 업로드→현지어 문구→광고 만들기→검수→세트 켜기 (확인 후)→심사 확인→예산 예약

셋팅 룰: 세트는 끄고(OFF), 광고는 켜서(ON) 만들어요.

세트가 꺼져 있으면 광고가 켜져 있어도 돈이 안 나가요. 집행할 때 세트만 켜면 광고가 바로 나가요. 세트를 켜는 건 꼭 확인받고 해요.

누가 무엇을

누가할 일
나클로드 켜기 · 메타 연결 · 토큰 「복사」 · 필수 6개 알려주기 · "켜요"라고 답하기
클로드파일 정리 · 캠페인·세트·광고 만들기 · 문구 · 예산·예약 · 심사 확인 · 결과 정리
사람만로그인 · 메타 계정 인증 · 파트너십(인플루언서) 광고

파트너십 광고는 클로드가 못 만들어요. 인플루언서 인스타 게시물을 광고 코드로 불러와 만드는 기능을 메타가 프로그램 연결(API)로 열어두지 않았어요. 회사 앱은 개발 모드라 쓸 수 없고, 메타 커넥터에도 인스타 게시물을 지정하는 항목이 없어요. 그래서 광고 관리자에서 사람이 직접 만들어요.

자주 하는 변경

요청클로드가 하는 일
"여기에 이 소재 추가해줘"그 세트에 소재를 올리고, 문구를 쓰고, 광고를 만들어요
"이미지 교체해줘"새 소재를 만들어 기존 광고에 갈아 끼워요. 광고 이름과 성과는 그대로 남아요
"히메카로 돌려줘"새 페이지로 광고를 만들고, 심사를 통과하면 예전 광고를 꺼요. 노출이 끊기지 않아요
"세트 분리해줘"같은 설정으로 세트를 하나 더 만들고, 예산을 반씩 나눠요
"24시 예산 변경 준비해"시트대로 예약을 걸고, 바뀌었는지 다시 확인해요
